# 실기기 QA 체크리스트 (출시 전)

세 앱 공통으로 **릴리스 APK를 실기기에 설치**해서 확인한다.
(릴리스 빌드는 debug와 동작이 다를 수 있어 반드시 릴리스로 테스트 — `docs/KNOWN_ISSUES.md` #3 참고)

APK 위치: `apps/<앱>/build/app/outputs/flutter-apk/app-release.apk`

## 공통 (3개 앱 모두)
- [ ] 설치 후 첫 실행 — 크래시 없이 빈 상태 화면이 뜬다
- [ ] 항목 추가 → **앱 완전 종료 후 재실행** → 데이터가 그대로 남아있다 ⭐
- [ ] 라이트/다크 전환 (구독노트·하루더는 우상단 토글, 시스템 설정도 함께)
  - [ ] 전환 후 **모든 화면**(목록·추가/수정·다이얼로그)에서 글자가 배경에 묻히지 않는다
- [ ] 홈 위젯 배치 → 값이 표시되고, 앱에서 데이터 변경 후 위젯에 반영된다
- [ ] 배너 광고가 하단에 뜬다 (하루더는 실 ID 미적용이라 안 떠도 정상)
- [ ] 뒤로가기로 앱이 이상 종료되지 않는다
- [ ] 알림 권한 거부 상태에서도 앱이 정상 동작한다 (크래시 X)

## D-Day
- [ ] 추가 → 목록 히어로 카드에 D-N이 맞게 표시
- [ ] **매년 반복** 켠 항목이 다음 도래일로 계산된다 (지난 생일 → 내년)
- [ ] 시작일 포함 토글이 D+ 숫자를 1 늘린다
- [ ] 스와이프 삭제 → **실행취소** 스낵바로 복구된다
- [ ] 알림: 날짜를 내일로 잡고 "1일 전" 켜기 → 오늘 알림 도착 확인
- [ ] 카카오 로그인 → 성공 (⭐ 릴리스 키 해시 확인용, 가장 중요)
- [ ] 로그아웃 → 로그인 화면으로 돌아간다
- [ ] 로그인 상태에서 항목 추가 → 앱 삭제 후 재설치 → 로그인 → **데이터 복원**

## 구독노트
- [ ] 빠른 추가(드롭다운)에서 넷플릭스 선택 → 이름·색이 자동 채워진다
- [ ] 월/연/주 각각 등록 → **이번 달 총액**이 맞게 합산된다 (연=÷12, 주=×52÷12)
- [ ] **주 구독**의 다음 결제일이 맞다 (오늘이 결제일이면 D-DAY) ⭐ 최근 수정
- [ ] 매월 31일 결제 등록 → 2월엔 말일로 표시된다
- [ ] 일시정지 토글 → 총액·활성 개수에서 빠지고 흐리게 표시
- [ ] 카테고리 필터가 목록을 올바르게 거른다
- [ ] "곧 결제 예정" 카러셀이 임박 순으로 뜬다
- [ ] 알림: 결제일을 내일로 + "1일 전" → 오늘 알림 도착

## 하루더
- [ ] 생성 마법사: 담배 → 시점 → 소비량 → 확인 흐름이 자연스럽다
- [ ] **종류 카드를 빠르게 두 번 탭해도 단계가 건너뛰어지지 않는다** ⭐ 최근 수정
- [ ] **"하루더 시작하기"를 연타해도 목표가 하나만 생성된다** ⭐ 최근 수정
- [ ] 직접 입력(커스텀) 경로에서 이름 단계가 추가로 나온다
- [ ] "잘 모르겠어요 · 건너뛰기" → 절약액 0으로 생성된다
- [ ] 홈: D+ 숫자, 절약액, 다음 이정표 진행바가 맞게 표시
- [ ] 이정표 알림: 끊은 시점을 **19분 40초 전**으로 잡으면 20초 뒤 "20분" 이정표 알림 도착 ⭐
- [ ] 수정 화면에서 "다시 시작" → 카운터 0, **최고기록은 유지**
- [ ] 목표 삭제 → 알림도 더 이상 오지 않는다

## 발견 시
이슈를 적어두고 알려주면 수정 후 재빌드한다.
