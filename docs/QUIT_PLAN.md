# 3번 앱 — "하루더" (금연·금주·커스텀 끊기 트래커) 기획

앱 이름 **하루더** ("하루 더 버티자"). 멀티 스코프 — 담배·술뿐 아니라 카페인·야식 등 커스텀 "끊기 목표" 여러 개.

> **핵심 차별점(1·2번과 다름):** 목표 **생성**은 토스식 **단계별 마법사**(한 단계씩 선택→자연스러운 전환)로,
> **수정**은 별도 일반 폼 페이지로 분리. 상세 UX는 Notion "하루더 — 기획/UX" 참고.

## 한 줄 가치
**끊은 지 얼마나 됐고, 그동안 얼마를 아꼈는지**를 매일 확인하며 버티는 힘을 얻는다. (D+ 카운터 + 절약 금액 + 건강 이정표)

## 핵심 훅
- **D+ 카운터** — 끊은 순간부터 경과 (일, 필요시 시:분). 위젯 주역
- **절약 금액** — 이전 소비(하루 비용) × 경과일
- **회피량** — 안 피운 개비 / 안 마신 잔 (하루 소비량 × 경과)
- **건강 이정표** — 시간 경과로 자동 달성 (금연: 20분→심박정상, 24시간→CO정상, 2주~3개월→폐기능…)
- **다시 시작(리셋) + 최고 기록** — 실패해도 리셋, `최고 연속일`은 보존 (죄책감보다 재도전)

## 데이터 모델 — `QuitItem` (freezed)
| 필드 | 설명 |
|---|---|
| id / name | |
| type | smoking / drinking / custom (이정표 세트·아이콘 결정) |
| quitDate | 끊은 일시 (시 단위까지 — 초반 시간 카운트용) |
| dailyCost | 이전 하루 지출(원) → 절약액 계산 |
| dailyUnits | 이전 하루 소비량(개비/잔/회) → 회피량 |
| unitLabel | 개비 / 잔 / 회 |
| bestStreakDays | 최고 연속 기록 (리셋해도 보존) |
| colorValue / createdAt | |

**계산 getter (순수·테스트 대상):** `elapsed`, `daysSince`, `moneySaved`, `unitsAvoided`, `현재/다음 이정표`.

## 화면
1. **홈** — 대표 목표 히어로(D+ 큰 숫자 + 절약액) + 스탯 타일(절약액/회피량/최고기록) + 다음 이정표 진행바. 목표 여러 개면 아래 카드 리스트(각 D+)
2. **목표 상세** — 큰 D+ 카운터 + 이정표 타임라인 + 절약액 상세 + "다시 시작"
3. **추가/편집** — 이름·종류·끊은 일시·이전 소비량(하루 비용/개비·잔)
4. **홈 위젯** — 대표 목표 D+ + 절약액
5. **알림** — 이정표 달성 축하 + (선택) 매일 응원 리마인드

## 건강 이정표 (type별)
- **금연**: 20분(심박·혈압)·8~12시간(CO 정상)·24시간(심장위험↓)·48시간(후각·미각)·2주~3개월(폐기능·순환)·1년(관상동맥 위험 절반)
- **금주**: 24시간·1주(수면·간)·2주·1개월(간지방↓)·3개월·1년
- **커스텀**: 일수 기반 범용(1·7·30·100·365일)

## 재사용 & 공장 개선
- core(저장/알림)·ads·홈위젯·릴리스 파이프라인 그대로
- ⭐ **구독노트의 다크/라이트 테마 시스템(`SubColors`/`sub_widgets`)을 공용 패키지로 추출** → 3번부터 재사용 (지금은 subscription 앱 내부). 이번에 추출하면 이후 앱은 테마를 공짜로 얻음
- 브랜드: 회복·성취의 **그린**(예: 0xFF12B76A) 계열 — 파이팅 톤

## 수익화
- 배너 광고. 향후 프리미엄(목표 무제한·상세 통계·광고 제거·위젯 테마)

## MVP 범위 & 단계
- **Phase 1 (로컬 MVP)**: 목표 등록/편집/삭제 · D+ · 절약액·회피량 · 이정표 · 리셋+최고기록 · 홈 위젯 · 알림 · 광고. 로그인/백엔드 없음
- **Phase 2**: 카카오 로그인 + 백업
- **Phase 3**: 통계·프리미엄

## 검수 포인트 (결정 필요)
1. 히어로 카운터: **일 단위** vs 초까지 실시간 틱 (동기부여 강하지만 배터리·복잡도↑) — MVP는 일+시간 권장
2. 다중 목표 UI: 카드 리스트 vs 상단 페이저 — 카드 리스트 권장
3. 이정표 문구: 의학 정보라 표현 순화("일반적으로 알려진" 등), 과장 금지
4. 테마 시스템 공용 추출 여부 (권장: 이번에 추출)
5. 최종 앱 이름 확정
